### Задание 1

Опишите основные преимущества использования масштабирования методами:

- активный master-сервер и пассивный репликационный slave-сервер; 
- master-сервер и несколько slave-серверов;
- активный сервер со специальным механизмом репликации — distributed replicated block device (DRBD);
- SAN-кластер.

*Дайте ответ в свободной форме.*

### Решение 1

1. Активный master и пассивный slave
Это когда один сервер (master) работает и на нём всё происходит, а второй (slave) просто копирует с него данные.
```
Плюсы:

Есть запасной сервер, если первый сломается.

Можно читать данные со второго сервера, чтобы не нагружать основной.

Легко настроить и понять.
```

2. Один master и много slave'ов
Это как первый вариант, но с несколькими копиями slave-серверов.

``` Плюсы:

Можно читать данные с разных серверов — быстрее обрабатываются запросы.

Если один slave упал — есть другие.

Можно использовать разные серверы для разных задач: один — для отчётов, другой — для резервного копирования и т.д.
```
3. Сервер с DRBD
DRBD — это такая технология, которая копирует данные с одного сервера на другой на уровне жёстких дисков (а не просто базы данных).
```
Плюсы:

Очень надёжно — данные копируются сразу, почти одновременно.

Подходит для "железных" серверов с высокой надёжностью.

Часто используется в кластерах, где два сервера работают как одно целое.
```
4. SAN-кластер
SAN — это как большой быстрый внешний жёсткий диск, к которому могут подключаться несколько серверов.

```
Плюсы:

Несколько серверов могут работать с одним и тем же хранилищем данных.

Очень быстро и удобно.

Можно добавить больше памяти или серверов без остановки работы.

Хорошо подходит для больших проектов и баз данных.
```
